# Ruvro & Co — Digital Showroom

Experiência editorial em Next.js para a curadoria privada Ruvro & Co.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Validação

```bash
npm test -- --run
npm run typecheck
npm run lint
npm run test:e2e
npm run build
```

Os produtos e a imagem principal são estudos demonstrativos, claramente identificados na interface. Antes da publicação oficial, substitua os dados e assets em `src/data/watches.ts` e `public/media/` por materiais aprovados pela Ruvro.
